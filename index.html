為什麼 Agent 是「循環」不是「一句話」

  • 單次問答：問一次、答一次，錯了不會修
  • Agent：思考 → 行動 → 觀察不斷往復，直到完成
  • 多個能力（檢索、工具、反思）用圖串接，每個方塊是一個節點

重點回顧

  • Agent 的心臟是迴圈（ReAct），不是更長的一次性提示
  • 反思讓迴圈越跑越好（Reflexion）
  • 工具擴大行動半徑（Toolformer）；記憶讓經驗可重複提取（Generative Agents）
  • 檢查節點把品質問題擋在生成之前（CRAG）
