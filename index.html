為什麼要講 Agent Loop？

  • 單純的 LLM：一次輸入 → 一次輸出（one-shot），錯了不會自己修。
  • AI Agent：把輸出回饋回輸入，形成 感知 → 思考 → 行動 → 觀察 的迴圈。
  • 本週主軸：Loop（迴圈）讓 agent 自我修正；Graph（圖）把多個節點接成流程。

Plan → Act → Observe → Reflect → (repeat)
